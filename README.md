📖 Overview

HCO Photo Hide is a sophisticated steganography tool that allows you to securely hide images behind password-protected codes. Share the generated code with others, and they can only view the original image by entering the correct password.

🚀 Quick Installation

For Termux Users:

```bash
# Update packages
pkg update && pkg upgrade -y

# Install dependencies
pkg install python git -y

# Install Python library
pip install colorama

# Clone repository
git clone https://github.com/HackersColonyTech/HCO-Photo-Hide.git

# Navigate to directory
cd HCO-Photo-Hide

# Run the tool
python hco_photo_hide.py
```

For Linux/Mac:

```bash
# Install Python3 and git
sudo apt update && sudo apt install python3 python3-pip git -y

# Clone repository
git clone https://github.com/HackersColonyTech/HCO-Photo-Hide.git

# Navigate to directory
cd HCO-Photo-Hide

# Run the tool
python3 hco_photo_hide.py
```

📸 How to Use

1. Hide an Image

· Select an image file from your device
· Set a strong, memorable password
· Click "Generate Secure Code"
· Share the generated code with recipients

2. View an Image

· Paste the received code in the view section
· Enter the correct password provided by the sender
· Click "View Hidden Image" to reveal the content

---

🌐 Network Sharing Guide

To share with others on your local network:

1. Find your IP address (check Termux with ifconfig or ip a)
2. Share this URL: http://YOUR_LOCAL_IP:8000
3. Others can access your HCO Photo Hide instance
4. Send codes through WhatsApp or other messaging apps
